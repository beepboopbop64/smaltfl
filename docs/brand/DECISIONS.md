# How the smaltfl brand is being chosen

A record of the brand work for smaltfl, in order, as smalt-brand's `DECISIONS.md` keeps one for every product. When
the brand is settled, this record moves into smalt-brand with the assets.

## Inputs

- **The family's rules** (smalt-brand `BRAND.md`): the `sm` + `alt` + suffix wordmark with `alt` in smalt; a
  "Small. Alternative. ___." tagline; a mark drawn as a smalt body and one chip in the product colour, in the Chevron
  style (solid bars, square-cut ends, 0°, 45° and 90°); a product colour from smalt's sibling cobalt pigments.
- **The product:** data pipelines for smaltdb, built visually and run in the browser, with an ontology, actions,
  policies and hashes attached to the data they produce.

## The words (decided, ADR 0001 §13)

| | **Picked** |
| --- | --- |
| Name | **smaltfl**, said "smalt-flow" |
| Tagline | **Small. Alternative. Flow.** |
| Positioning | **Data pipelines for smaltdb.** |

## Round 1: five marks in three colours

- **Marks:** M1 Fork, M2 Merge, M3 Relay, M4 Pipe-forward, M5 Stages (added because Relay read as a plug at 16 px).
- **Colours:** C1 cobalt teal, C2 plum, C3 smalt only. The colour wheel is nearly full: no hue at the family's chroma
  is more than about 35 (CIE76) from every product and status colour, and cobalt teal had been ruled out twice for
  sitting near smaltui's cerulean.

Feedback:

- **Colour:** cobalt teal, the favourite.
- **Marks:** none felt like a flow. The bars (Stages) came closest, without convincing.

| | **Picked** |
| --- | --- |
| Colour | **Cobalt teal:** `#00786F` fill, `#006861` text (6.2:1 on `bg`), `#4FD1C5` on dark (9.6:1) |
| Mark | None; a second round |

## Round 2: marks that read as flow

All in cobalt teal, each saying flow a different way: M6 Cascade (the Stages bars joined into one staircase), M7
Stream (two arrows and a packet), M8 Tide (two waves in 45° steps), M9 Bend (a path that changes lanes), M10 Pour (a
pipe and a drop), and M11 Wave, which needs a curve: an exception to the angle rule, as smaltql's Star is one.

Dropped while drawing: a Meander (one pipe snaking back and forth), which read as the digit 2, and a steeper Bend,
which read as a backslash and a dot.

Feedback: pending.
