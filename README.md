# smaltfl

Data pipelines for smaltdb, built visually and run in the browser: flows that turn sources into datasets, with an
ontology, lineage and ownership attached to the data they produce. A planned member of the
[smalt family](https://smaltworks.dev).

> **Status: design interview.** There is no code yet. The questions that shape the architecture and the brand are in
> [docs/OPEN_QUESTIONS.md](docs/OPEN_QUESTIONS.md); their answers become the first ADRs in `docs/adr/`. What the
> family already provides, and the conventions smaltfl follows, are in
> [docs/research/ecosystem-survey.md](docs/research/ecosystem-survey.md).
